# AI SQL Agent

A Python project that lets you ask business questions in plain English and get:
- an SQL query generated by an LLM,
- the executed database result,
- and a plain-English answer.

It supports both:
- a terminal interface (`cli.py`), and
- a Streamlit web app (`app.py`).

The app is built around a SQLite database (`orders.db`) created from Uber Eats sales data (`data/ubereats_sales.csv`).

## Features

- Natural language to SQL using LangChain + Mistral
- SQLite analytics on an `orders` table
- Verbose agent reasoning/tool calls (for learning and debugging)
- Streamlit chat UI with:
  - query history,
  - generated SQL display,
  - intermediate tool steps,
  - session stats
- Deterministic SQL generation (`temperature=0`)

## Project Structure

- `agent.py`: Core agent pipeline (DB, LLM, tools, executor, query runners)
- `app.py`: Streamlit frontend
- `cli.py`: Terminal interface
- `config.py`: Central configuration (DB path, model, temperature, verbosity, env key check)
- `prompts.py`: System prompt with schema + strict rules
- `setup_db.py`: CSV -> SQLite loader script
- `requirements.txt`: Python dependencies
- `data/ubereats_sales.csv`: Source dataset used to build the DB
- `orders.db`: Generated SQLite database file
- `.env`: Environment variables (e.g., API key)

## How It Works

1. `agent.py` connects to SQLite through LangChain `SQLDatabase`.
2. It initializes `ChatMistralAI` using `MISTRAL_API_KEY` from environment variables.
3. `SQLDatabaseToolkit` provides SQL tools (`list_tables`, `schema`, `query_checker`, `query`).
4. A tool-calling agent is built manually with `create_tool_calling_agent` and `AgentExecutor`.
5. User questions are sent to the agent, which calls tools, runs SQL, and returns a final answer.

The project intentionally avoids `create_sql_agent` and builds the prompt/agent manually for Mistral compatibility.

## Prerequisites

- Python 3.10+
- A Mistral API key from https://console.mistral.ai/

## Setup

### 1) Create and activate a virtual environment

Windows (CMD):

```bat
python -m venv venv
venv\Scripts\activate
```

Windows (PowerShell):

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
python -m venv venv
source venv/bin/activate
```

### 2) Install dependencies

```bash
pip install -r requirements.txt
```

### 3) Configure environment variables

Create/update `.env` in the project root:

```env
MISTRAL_API_KEY=your_mistral_api_key_here
```

Note: `config.py` raises an error at startup if this key is missing.

### 4) Build the SQLite database from CSV

```bash
python setup_db.py
```

This creates/replaces `orders.db` with an `orders` table.

## Run the Project

### Option A: CLI

```bash
python cli.py
```

Example questions:
- What is total revenue by city?
- Average delivery time for completed orders
- Top 5 food categories by revenue
- Which city has the highest average rating?
- How many orders were cancelled?

### Option B: Streamlit App

```bash
streamlit run app.py
```

Open the local URL shown in terminal (usually `http://localhost:8501`).

## Configuration

Edit `config.py` to adjust runtime behavior:

- `DB_PATH`: SQLite file path (default `orders.db`)
- `MODEL_NAME`: Mistral model (default `mistral-small-latest`)
- `TEMPERATURE`: Keep `0` for deterministic SQL
- `VERBOSE`: `True` to print detailed tool-call traces

## Prompt and SQL Safety

`prompts.py` includes strict guardrails:

- Use only the `orders` table
- Use only listed schema columns
- Do not hallucinate missing fields/tables
- Use valid SQLite syntax

These constraints significantly improve query reliability.

## Troubleshooting

- Error: `MISTRAL_API_KEY environment variable is not set`
  - Add key to `.env` (or export/set env var in shell) and restart.

- App runs but answers fail
  - Ensure `orders.db` exists and contains the `orders` table.
  - Rebuild DB with `python setup_db.py`.

- Import/version issues
  - Recreate venv and reinstall: `pip install -r requirements.txt`
